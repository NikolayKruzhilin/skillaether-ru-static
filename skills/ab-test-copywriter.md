# Копирайтер A/B-Тестов

## Фреймворк дизайна тестов
Для каждого теста необходимо определить:
1. **Гипотеза**: Изменение [X] на [Y] увеличит [метрику], так как [причина]
2. **Контроль**: Текущий текст (в точности)
3. **Вариант**: Новый текст (строго одно изменение)
4. **Ключевая метрика**: CVR, CTR или регистрации
5. **Размер выборки**: Используйте калькулятор (см. ниже)
6. **Длительность**: Минимум 2 бизнес-цикла (обычно 2 недели)

## Расчет размера выборки (Sample Size)
```
Базовый CVR: напр., 3%
Минимальный ожидаемый эффект: напр., прирост в 20% → целевой 3.6%
Статистическая значимость (Statistical significance): 95%
Мощность теста (Power): 80%
Результат: ~3,500 посетителей на каждый вариант

Эмпирическое правило: если у вас меньше 100 конверсий в неделю, не запускайте A/B-тесты — используйте качественные исследования пользователей.
```

## CTA-варианты для обязательного тестирования
| Элемент | Контроль | Идеи для варианта |
|---------|----------|-------------------|
| Текст CTA | "Начать" | "Начать Бесплатно", "Попробовать Бесплатно", "Смотреть в действии" |
| Заголовок | Фокус на фичах | Фокус на выгоде, вопрос, цифра |
| Social proof | Блок с логотипами | Цитата из отзыва, счетчик оценок |
| Срочность | Отсутствует | "Осталось мало мест", "Ограниченное предложение" |

## Частые идеи для A/B-тестов (по уровню влияния)
1. Заголовок на главном скрине (самое сильное влияние)
2. Текст на кнопке (CTA)
3. Подзаголовок / Value Proposition
4. Тип социальных доказательств (логотипы vs цитаты vs цифры)
5. Количество полей в форме (Меньше полей = Выше CVR)
6. Главное изображение (Люди vs Интерфейс продукта vs Абстракция)

## Как правильно интерпретировать результаты
- Дождитесь, пока не будет достигнут объём выборки И полная длительность теста
- Смотрите на весь доверительный интервал (confidence interval), а не только на точечную оценку
- Сегментируйте результаты по источникам трафика — разная аудитория конвертится по-разному
- Не останавливайте тест раньше времени, даже если результаты сразу кажутся отличными
