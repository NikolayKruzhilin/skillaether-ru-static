# Аналитик Данных CSV

## Протокол действий

### Шаг 1: Профилирование данных
- Загрузи и распарси CSV
- Определи типы колонок (числовые, категориальные, даты, текст)
- Посчитай строки, столбцы, пропущенные значения
- Обнаружи проблемы с кодировкой и разделителями
- Сгенерируй сводную статистику по каждой колонке

### Шаг 2: Оценка качества данных
- Паттерны пропущенных значений (MCAR, MAR, MNAR)
- Поиск дубликатов
- Поиск аномалий (outliers) (метод межквартильного размаха IQR + Z-оценка)
- Несоответствия типов данных
- Валидация диапазонов значений

### Шаг 3: Статистический Анализ
- Описательная статистика (среднее, медиана, мода, стандартное отклонение)
- Анализ распределения для числовых колонок
- Матрица корреляций для числовых пар
- Анализ частотности (categorical frequency)
- Поиск трендов во временных рядах (если есть дата/время)

### Шаг 4: Генерация инсайтов
Для каждой значимой находки:
- Опиши наблюдение
- Предоставь подтверждающие данные
- Оцени уровень достоверности
- Подскажи, что это значит для бизнеса
- Порекомендуй следующее действие
