# Фреймворк Левел-Дизайна

## Структура уровня в 3 акта
```
Акт 1 (20%): Введение
  — Безопасное пространство, никакого давления
  — Введи механику без риска для жизни игрока
  — Игрок экспериментирует и обретает уверенность

Акт 2 (60%): Усложнение
  — Примени механику под давлением
  — Добавляй дополнительные механики слоями
  — Выстраивай путь к испытанию на навык (skill challenge)

Акт 3 (20%): Развязка
  — Комбинируй все механики этого уровня
  — Кульминационное испытание
  — Награда и переход на новый уровень
```

## Обучение механикам без текста
Метод Nintendo — показывай, а не рассказывай:
1. Покажи врага в безопасном контексте (игрок может наблюдать поведение)
2. Дай легкую версию испытания (низкие ставки)
3. Дай сложную версию (давление временем, несколько врагов)
4. Проверка мастерства (комбинирование с прошлыми механиками)

## Шаблон карты потока (Flow Map)
```
[Старт] → [Безопасная зона] → [Обучающий бит 1]
                                   ↓
                             [Испытание 1]
                                   ↓
                         [Награда / Передышка]
                                   ↓
                  [Испытание 2 — механика +]
                                   ↓
                      [Босс / Кульминация]
                                   ↓
                        [Финал / Награда]
```

## Ритм (Pacing Beats — ритм имеет значение)
```
Напряжение → Разрядка → Напряжение → Разрядка

Высокое напряжение: Бой, пазл на время, босс
Среднее напряжение: Исследование, мелкие враги
Разрядка: Комната с наградой, безопасная зона, катсцена, красивый вид

Никогда не ставь 2 момента высокого напряжения подряд без разрядки.
```

## Повествование через окружение (Environmental Storytelling)
- Используй декорации, чтобы намекнуть на историю без текста
- Читаемые силуэты: игроки должны понимать объекты по форме
- Контраст привлекает внимание: свет = безопасность/награда, тьма = опасность
- Пути и подсказки должны направлять без невидимых стен

## Чек-лист плейтеста
- [ ] Может ли новый игрок пройти это без подсказок?
- [ ] Где игроки умирают чаще всего? (добавь помощь или снизь сложность)
- [ ] Очевиден ли критический путь без навязывания?
- [ ] Разнообразен ли темп (нет ли двух одинаковых этапов подряд)?
- [ ] Обучает ли этот уровень тому, что потребуется на СЛЕДУЮЩЕМ уровне?
