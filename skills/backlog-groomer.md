# Грумер Бэклога

## Протокол сессии груминга

### Шаг 1: Сортировка (Triage) (15 мин)
К каждому элементу в списке задай вопросы:
- Это всё ещё актуально? (Если нет → В архив)
- Это дубликат? (Если да → Объедини)
- На самом деле это сразу несколько задач? (Если да → Разбей на части)

### Шаг 2: Оценка (10 мин)
| T-Shirt | Story Points | Правило для оценки |
|---------|-------------|--------------------|
| XS | 1 | < 2 часов |
| S | 2 | Половина рабочего дня |
| M | 3 | 1-2 дня |
| L | 5 | 3-4 дня |
| XL | 8 | Нужно декомпозировать (слишком велико) |

Эмпирическое правило: Если команда не может сойтись в оценке, значит, для стори не хватает контекста.

### Шаг 3: Проверка критериев приемки (Acceptance Criteria)
Каждая задача уровня P0/P1 обязана иметь:
- [ ] Формат User story (Я как [пользователь], хочу [действие], чтобы [результат])
- [ ] Как минимум 2 критерия приемки
- [ ] Описанные краевые случаи (edge cases)
- [ ] Прикрепленную ссылку на мокап или макет дизайна

### Шаг 4: Приоритезация
Автоматически применяй RICE-скоринг или матрицу Бизнес-ценность / Усилия:
```
Высокая ценность + Мало усилий  → Сделай в следующем спринте
Высокая ценность + Много усилий → Запланируй + разбей на этапы
Низкая ценность + Мало усилий   → Сделай при наличии свободных ресурсов
Низкая ценность + Много усилий  → Удали или отправь в бэклог
```

## Формат для импорта в Linear/Jira
```
Title: [Название истории]
Description: Как [пользователь], я хочу [сделать действие], чтобы получить [результат]
Acceptance Criteria:
- Given/When/Then 1
- Given/When/Then 2
Estimate: [оценка]
Priority: [Urgent/High/Medium/Low]
Labels: [feature, bug, chore]
```
