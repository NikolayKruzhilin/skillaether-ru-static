# Дизайнер Вариантов Лендинга

## Вводные данные от тебя
- Название продукта/услуги и основное предложение (оффер)
- Целевая аудитория и главная 'боль'
- Текущий коэффициент конверсии (CVR), если известен
- 3 самых сильных социальных доказательства (отзывы, цифры)
- Главная цель CTA (регистрация / демо / покупка)

## Вариант A: От Результата (рекомендуемая база)
```
Первый экран (Hero):
  H1: "[Тот результат, который они хотят] — без [того, что они ненавидят]"
  Подзаголовок: Для кого это + как это работает одной строкой
  CTA: "Начать [глагол результата] бесплатно" (например, "Начни автоматизировать")
  Визуал: Скриншот продукта или иллюстрация результата

Секция 2: Проблема (нагнетание/agitate)
Секция 3: Как это работает (3 простых шага)
Секция 4: Социальные доказательства (цитаты + метрики)
Секция 5: Фичи (удобные для беглого просмотра)
Секция 6: FAQ (снятие возражений)
Секция 7: Повтор CTA из начала страницы
```

## Вариант B: От Социальных Доказательств
```
Первый экран (Hero):
  Вступление: Стена логотипов или "Нам доверяют X,000+ команд"
  H1: "[Инструмент], который использует [известный клиент]"
  CTA: "Присоединиться к [X] командам"
  Визуал: Стена отзывов / звезды рейтингов

Секция 2: Фокус на Кейс-стади (конкретная метрика успеха)
Секция 3: Доказательство фичами (фичи привязаны к результатам)
Секция 4: Еще больше отзывов (из разных сегментов)
```

## Вариант C: От Проблемы (для рынков с «высокой болью»)
```
Первый экран (Hero):
  H1: "Всё еще делаешь [боль] вручную?"
  Подзаголовок: Прямое попадание в точку фрустрации
  CTA: "Хватит тратить время →"

Секция 2: Нагнетание боли (больше деталей о проблеме)
Секция 3: Явление решения
Секция 4: Быстрое сравнение (до / после)
```

## Тексты кнопок CTA для теста
- Общий (база): "Начать пользоваться"
- От результата: "Начни [цель] сегодня"
- Снижение трения: "Попробуй бесплатно — карта не нужна"
- Срочность: "Присоединяйся до [дата]"

## Чек-лист 'Первого экрана' (Above-the-Fold)
- [ ] Понятный H1 (что это вообще такое?)
- [ ] Подзаголовок (для кого это?)
- [ ] Один CTA (не два)
- [ ] Визуальное доказательство (не абстрактная картинка)
- [ ] Сигнал доверия (отзывы, логотипы или число юзеров)
