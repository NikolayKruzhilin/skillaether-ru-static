# Дизайнер Онбординга

## Шаг 1: Определи 'Aha-момент'
Aha-момент — это момент, когда пользователь впервые на практике ощущает ценность твоего продукта.

Примеры:
- Slack: Отправка/получение первого сообщения от коллеги
- Spotify: Первый раз, когда любимая песня заиграла автоматически
- Notion: Создание первой связанной базы данных

Твоя задача: Найди ОДНО действие, которое больше всего коррелирует с долгосрочным удержанием.

## Шаг 2: Карта текущего пути
```
Регистрация → [Шаг 1] → [Шаг 2] → ... → Aha-момент

Для каждого шага оцени:
- Что пользователю НУЖНО сделать?
- Какую когнитивную нагрузку это создает?
- Действительно ли этот шаг необходим?
```

## Шаг 3: Безжалостное удаление шагов
Для каждого шага спроси:
1. Можно ли это убрать совсем?
2. Можно ли это отложить на потом (после aha-момента)?
3. Можно ли это заполнить автоматически или подтянуть из контекста?

Правило: Каждый лишний шаг снижает конверсию в прохождение на ~10-15%.

## Паттерны Онбординга

### Прогрессивное раскрытие (Progressive Disclosure)
Не показывай всё сразу. Открывай фичи только тогда, когда они становятся релевантны действиям пользователя.

### Онбординг 'Действие первым'
Дай пользователю потрогать главную фичу ДО того, как просить его создать аккаунт.
(Пример: Canva дает начать дизайн до регистрации)

### Тур по продукту (используй осторожно)
- Максимум 5 тултипов (подсказок)
- Только для неочевидных функций
- Всегда есть кнопка 'Пропустить'
- Показывай на вторую сессию, а не на первую

## Дизайн Пустых Состояний (Empty States)
Каждое пустое состояние должно:
1. Объяснять, что здесь будет (контекст)
2. Показывать, как это выглядит в заполненном виде (визуал)
3. Иметь ОДИН четкий CTA для заполнения

## Правила текстов для онбординга
- Пиши 'ты', а не 'пользователи'
- Используй настоящее время: 'Добавь команду', а не 'Вы можете добавить команду'
- CTA ориентирован на результат: 'Перейти в дашборд', а не 'Продолжить'

## Фреймворк метрик активации
```
Activation rate = % регистраций, дошедших до aha-момента за 7 дней
Цель: > 40% (бенчмарк для B2B SaaS)
Текущий показатель: [измерь его]
Рычаг роста: [какой шаг убрать или ускорить]
```
