# Календарь Контента для Соцсетей

## Вводные данные от тебя
1. Название бренда/продукта и ниша
2. Целевая аудитория (кто они и на какой стадии воронки)
3. 3 столпа контента (например: обучение, экспертность, закулисье, промо)
4. Даты промо-акций или запусков в ближайшие 30 дней
5. Голос бренда (2-3 прилагательных)
6. Платформы (Twitter/X, LinkedIn, Instagram)

## Пропорция контента на 30 дней
```
Неделя 1: 2 обучающих + 1 личная история + 1 вовлекающий
Неделя 2: 2 обучающих + 1 кейс (соц. доказательство) + 1 промо
Неделя 3: 2 обучающих + 1 'закулисье' + 1 вовлекающий
Неделя 4: 1 обучающий + 1 личная история + 2 промо (дожим под конец месяца)
```

## Лучшее время для постинга
| Платформа | Лучшее время |
|----------|------------|
| Twitter/X | Будни 8-10 утра, 12 дня, 5-6 вечера |
| LinkedIn | Вторник-четверг, 8-10 утра |
| Instagram | Ежедневно 11:00-13:00, 19:00-21:00 |

## Списки идей для контента
- **Советы и фреймворки**: "3 способа [достичь X]", "Фреймворк [имя] для [тема]"
- **Закулисье (BTS)**: Building in public, команда, процессы изнутри
- **Кейсы и отзывы**: Цитаты клиентов, графики роста, до/после
- **Острое мнение**: "Почему [популярная вещь] на самом деле не работает"
- **Вовлечение**: Опросы, открытые вопросы, фразы 'дополни предложение'
- **Промо**: Фичи продукта, офферы, анонсы запусков

## Стратегия Хэштегов
- Instagram: 5-10 нишевых тегов (от 100к до 1М постов), 2-3 брендовых
- LinkedIn: 3-5 релевантных тегов, не больше
- Twitter/X: 1-2 максимум, или вообще без них для лучшего охвата

## Формат Вывода
Для каждого поста:
```
Дата: [День, Число]
Платформа: [Платформа]
Столп: [Название столпа]
Текст: [Полный текст поста]
Теги: [список хэштегов]
Визуал: [Краткое описание картинки/видео]
```
