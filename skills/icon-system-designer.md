# Дизайнер Иконочных Систем

## Выбор стиля иконок (выбери один)
| Стиль | Ощущение | Примеры |
|-------|------|----------|
| Контурный (Outline) | Современный, чистый | Heroicons, Feather |
| Залитый (Filled) | Акцентный, четкий в малых размерах | Material Icons |
| Двухцветный (Duotone) | Премиальный, выразительный | Phosphor Icons |
| Иллюстративный | Уникальный, брендированный | Только кастомные |

## Сетка (Grid System)
```
Базовый холст: 24×24px (самый частый)
Безопасная зона (Safe zone): 20×20px (держи все формы внутри)
Зона выхода за края (Bleeding zone): 2px по краям (для оптического баланса)
Толщина обводки (Stroke): 1.5px для 24px, масштабируй пропорционально
Радиус скругления: 2px (для кончиков линий и углов)
```

## Правила Консистентности
1. Одинаковая толщина линий во всех иконках
2. Одинаковый радиус скругления везде
3. Пиксель-перфект (pixel-perfect) в целевых размерах
4. Оптическое выравнивание размеров (некоторые формы должны быть чуть больше, чтобы казаться равными)
5. Никакой лишней детализации (если деталь пропадает на 16px — удаляй её)

## Шкала Размеров
```
xs: 12px — внутри строки с мелким текстом
sm: 16px — внутри основного текста
md: 20px — по умолчанию
lg: 24px — кнопки, навигация
xl: 32px — акценты на фичах
2xl: 48px+ — иллюстрации, пустые состояния (empty states)
```

## Настройка Компонентов в Figma
```
Структура библиотеки иконок:
  icons/
    ├── 24px/
    │   ├── arrows/
    │   ├── ui/
    │   ├── media/
    │   └── social/
    ├── 20px/ (те же категории)
    └── 16px/ (только самые частые)

Именование: icon/[категория]/[имя] — например, icon/ui/arrow-right
Варианты (Variants): size (16/20/24), weight (regular/bold)
```

## React-компонент Иконки
```tsx
interface IconProps { size?: number; color?: string; className?: string; }

export function ArrowRight({ size = 20, color = 'currentColor', className }: IconProps) {
  return (
    <svg width={size} height={size} viewBox="0 0 24 24" fill="none"
      stroke={color} strokeWidth="1.5" strokeLinecap="round" strokeLinejoin="round"
      className={className}>
      <path d="M5 12h14M12 5l7 7-7 7" />
    </svg>
  );
}
```
