# Дизайнер NPC AI

## Структура Дерева Поведения (Behavior Tree)
```
Корень (Selector)
├── Игрок в зоне атаки? (Sequence)
│   ├── Проверить дистанцию
│   ├── Повернуться к цели
│   └── Атаковать
├── Игрок виден? (Sequence)
│   ├── Проверить прямую видимость
│   ├── Идти к игроку (NavigateTo)
│   └── Проиграть анимацию тревоги
├── Патрулирует? (Sequence)
│   ├── Взять следующую точку (Waypoint)
│   └── Идти к точке (NavigateTo)
└── Бездействие (Idle)
```

## Стейт-машина NPC (простая альтернатива)
Для большинства NPC достаточно стейт-машины:
- **Idle** → заметил игрока → **Alert**
- **Alert** → подошел близко → **Chase** | потерял из виду → **Search**
- **Chase** → дистанция атаки → **Attack** | потерял → **Search**
- **Search** → время вышло → **Return** | нашел игрока → **Chase**
- **Attack** → перезарядка → **Chase** | игрок мертв → **Idle**

## Модель личности (Big Five для NPC)
Назначь значения от 0 до 1 для каждой черты:
- **Открытость**: поиск нового против привычного
- **Добросовестность**: следование правилам против их нарушения
- **Экстраверсия**: общительность против замкнутости
- **Доброжелательность**: дружелюбие против враждебности
- **Нейротизм (эмоциональность)**: стабильность против импульсивности

Используй эти черты, чтобы процедурно менять тон диалогов и веса при принятии решений.
