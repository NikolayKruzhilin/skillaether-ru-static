# Фреймворк OKR (Objectives and Key Results)

## Формула OKR

**Цель (Objective)**: Вдохновляющая, качественная, задающая вектор
Плохо: "Увеличить выручку"
Хорошо: "Стать бесспорным лидером рынка для HR-команд в малом и среднем бизнесе"

**Ключевой Результат (Key Result)**: Количественный, ограниченный по времени, ориентированный на результат (а не на действие)
Плохо: "Запустить 3 новые фичи" (это действие/activity)
Хорошо: "Увеличить уровень принятия (adoption rate) новых фич с 20% до 45%" (это результат/outcome)

## Чек-лист качества OKR
- [ ] Цель запоминающаяся и мотивирующая
- [ ] Ключевые результаты — это метрики, а не список задач
- [ ] Каждый KR можно оценить по шкале от 0.0 до 1.0
- [ ] Ожидаемый балл 0.7 = амбициозно, но достижимо
- [ ] Максимум 3-5 KR на одну Цель
- [ ] Ключевые результаты достижимы независимо друг от друга

## Пример OKR уровня компании
```
Цель: Достичь Product-Market Fit с крупными корпоративными клиентами

KR1: Вырастить ARR с $500k до $1.2M
KR2: Добиться NPS 50+ среди корпоративных аккаунтов
KR3: Снизить ежемесячный отток (churn) с 8% до 3%
KR4: Закрыть 3 сделки с крупными брендами (логотипами) от 1000 рабочих мест
```

## Каскадирование OKR на команды
```
OKR Компании → OKR Инженерного отдела

Цель: Обеспечить надежность платформы, которую требуют корпорации
KR1: Добиться аптайма 99.95% (вместо 99.7%)
KR2: Снизить время решения инцидентов P1 с 4 часов до 45 минут
KR3: 100% API задокументированы и версионированы
```

## Шкала оценки (Grading Rubric)
| Балл | Значение |
|-------|--------|
| 0.9–1.0 | Перевыполнено — не слишком ли легко было?
| 0.7–0.8 | Идеально — амбициозно, но сделано |
| 0.4–0.6 | Частично выполнено — что помешало прогрессу? |
| 0.0–0.3 | Провал — нужно найти корневую причину |

## Квартальный ритм
- Неделя 1: Постановка OKR, согласование с руководством
- Ежемесячно: 15-минутный чекап OKR в команде
- Неделя 12: Оценка и ретроспектива
- Неделя 13: Выводы переходят в планирование следующего квартала
