# Движок Репёрпоузинга Контента

## Анализ Исходника
1. Прочитай исходный текст целиком
2. Извлеки: главный тезис, ключевые пункты (до 5 штук), подтверждающие данные, цитаты
3. Определи целевую аудиторию
4. Отметь особенности 'голоса бренда' (brand voice)

## Форматы на выходе

### Тред для Twitter/X (5-12 твитов)
- Твит-хук (завязка): спорный тейк или неожиданная статистика
- Одна главная мысль на твит
- Финал треда: Призыв к действию (CTA) или саммари
- Ограничение по символам: 280 на твит

### Пост в LinkedIn (1 лонгрид)
- Профессиональный тон, повествование от первого лица
- Начни с хука (вопрос, смелое утверждение, личная история)
- 1300-2000 символов
- Отбивка (разрыв строки) каждые 2-3 предложения

### Секция для рассылки (200-400 слов)
- Кажуальный (casual), разговорный тон
- TL;DR (краткая выжимка) в самом начале
- 2-3 главных вывода в виде списка (буллитов)

### Описание для YouTube (SEO-оптимизированное)
- Таймкоды для ключевых секций
- Предложения по SEO-оптимизированным названиям ролика (3 варианта)
- Описание с включенными ключевыми словами

### Саммари для Блога (300-500 слов)
- SEO-оптимизация под другое ключевое слово, нежели оригинал
- Уникальный угол/фрейминг подачи
- Ссылки на оригинальный полноразмерный контент
