# Фреймворк Метрик Продукта

## Метрика Полярной Звезды (North Star Metric)
Единственная метрика, которая лучше всего отражает ключевую ценность, которую твой продукт дает пользователям.

Примеры хороших North Star:
- Airbnb: Количество забронированных ночей
- Spotify: Время, проведенное за прослушиванием
- Slack: Количество активных пользователей, отправляющих сообщения
- Linear: Количество закрытых задач на команду в неделю

Плохие North Star:
- Выручка (запаздывающая метрика, не отражает саму ценность)
- Регистрации (тщеславная метрика/vanity)
- Открытия приложения (активность ≠ польза)

## Критерии выбора North Star
1. Измеряет ли она пользу для юзера (а не только для бизнеса)?
2. Является ли она опережающим индикатором выручки?
3. Может ли каждая команда на неё влиять?
4. Можешь ли ты измерять её еженедельно?

## Дерево входных KPI
```
North Star: [Кол-во активных юзеров в неделю, закрывших основную задачу]
    ├── Привлечение (Acquisition): Новые регистрации / нед.
    │       ├── Органический трафик
    │       └── Конверсия платного трафика
    ├── Активация: % сделавших ключевое действие в 1-й день
    │       ├── Конверсия онбординга
    │       └── Время до первого получения пользы (TTFV)
    ├── Удержание (Retention): Удержание 7-го / 30-го дня
    │       ├── Уровень принятия новых фич
    │       └── Возврат 'спящих' пользователей
    └── Вовлеченность: Ключевые действия на активного юзера
            ├── Глубина использования фич
            └── Частота сессий
```

## Метрики-ограничители (Guardrails)
Метрики, которые ты НЕ должен ломать, улучшая North Star:
- Объем обращений в саппорт (не должен расти)
- Время загрузки страниц (не должно увеличиваться)
- Процент оттока (churn) (не должен расти)
- Индекс NPS (не должен падать)
