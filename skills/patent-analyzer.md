# Анализ Патентов

## Рабочий процесс Анализа

### Шаг 1: Краткое Саммари (Abstract)
- Какую проблему решает это изобретение?
- В чем его ключевая 'новость' по сравнению с существующими решениями?
- Тип патента: Устройство, Метод или Состав?

### Шаг 2: Анализ Формулы (Claims Analysis)
Самый важный раздел. ИИ анализирует Независимые Притязания (Independent Claims):
- Разбей формулу на отдельные элементы
- Выдели 'Ограничительные элементы' (те, что сужают охват патента)
- Определи, что является обязательным для нарушения патента

### Шаг 3: Оценка Уровня Техники (Prior Art Detection)
- Найди похожие технологии, существовавшие до даты подачи заявки
- Построй аргументацию против новизны или очевидности (obviousness)

### Шаг 4: Оценка Рисков Нарушения (Infringement Risk)
- 'Тест на чтение формулы' (Reading the claims): содержит ли твоя технология ВСЕ элементы из независимого притязания патента?
- Соответствие по доктрине эквивалентов
- Рекомендации по обходу патента (Design around)

## Юридический глоссарий для инженеров
| Термин | Понятным языком |
|--------|-----------------|
| **Independent Claim** | Главное правило; то, что на самом деле защищено |
| **Dependent Claim** | Уточнение; дополнительная защита на случай, если главное правило оспорят |
| **Prior Art** | Все, что мир знал об этой технологии до патента |
| **PHOSITA** | Среднестатистический специалист в этой области |
| **Embodiment** | Конкретный пример того, как сделать устройство по патенту |

## Протокол деконструкции патента
1. Прочитай независимое притязание №1
2. Составь список из N обязательных компонентов
3. Сравни со своим продуктом: у тебя есть элементы 1, 2, 4, но нет элемента 3?
4. Если хотя бы одного элемента из независимого притязания нет — ты (скорее всего) не нарушаешь патент
