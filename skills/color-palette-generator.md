# Генератор Цветовой Палитры Бренда

## Входные данные
- Вайб бренда (3 прилагательных)
- Индустрия (влияет на психологические ожидания от цвета)
- Основное место использования (веб-приложение, лендинг, мобильное приложение)
- Есть ли уже какие-то цвета, которые нужно сохранить?
- Тебе нужны светлая, тёмная или обе темы?

## Структура цветовой системы
Для каждого бренда создай 5 цветовых шкал:
1. **Primary (Основной)** — главный цвет бренда, кнопки (CTA), ссылки
2. **Secondary (Вторичный)** — поддерживающий акцентный цвет
3. **Neutral (Нейтраль)** — текст, фоны, бордеры
4. **Success (Успех)** — подтверждения, позитивные стейты (зеленое семейство)
5. **Error (Ошибка)** — деструктивные действия, ошибки (красное семейство)

## Шкала из 10 оттенков
Сгенерируй оттенки для каждого цвета: 50, 100, 200, 300, 400, 500, 600, 700, 800, 900
- 50: почти белый тон (для фонов, состояний hover)
- 100-300: светлые тона (деликатные фоны, бейджи)
- 400-500: средние тона (иконки, бордеры)
- 600: основной оттенок из палитры (главный цвет бренда)
- 700-900: темные тона (hover для кнопок, текст на светлом фоне)

## Требования к контрастности (WCAG)
| Комбинация | Мин. Коэффициент | Разрешено |
|-------------|--------------|--------|
| Обычный текст на фоне | 4.5:1 | 7:1 |
| Крупный текст на фоне | 3:1 | 4.5:1 |
| UI элементы | 3:1 | 4.5:1 |

Всегда тестируй: primary-600 на белом, белый на primary-600.

## Вывод CSS Переменных
```css
:root {
  --color-primary-50: #EFF6FF;
  --color-primary-500: #3B82F6;
  --color-primary-600: #2563EB;
  --color-primary-900: #1E3A5F;
}

[data-theme="dark"] {
  --color-bg: var(--color-neutral-900);
  --color-text: var(--color-neutral-50);
  --color-surface: var(--color-neutral-800);
}
```
