# Анализ Оттока Клиентов

## Сегментация Оттока (сделай это в первую очередь)
Не каждый отток равнозначен. Разбей на сегменты перед анализом:

| Сегмент | Определение | Приоритет |
|---------|-----------|----------|
| Недобровольный | Ошибка оплаты | Исправь немедленно — это деньги |
| Ранний | Ушли до 30-го дня | Проблема с Активацией |
| Средний (Mid-life) | Ушли на 2-6 месяц | Проблема с получением Ценности |
| Поздний | Ушли после 6+ месяцев | Ушли к конкурентам или сменили профиль |
| Спящие (Dormant) | Все еще платят, но не заходят | Высокий риск потери в будущем |

## Поиск моментов оттока (Churn Moment Mapping)
Найди последнее действие для каждого сегмента перед отвалом:
1. Выгрузи лог событий для отвалившихся юзеров (за последние 30 активных дней)
2. Найди последнюю фичу, которую они трогали
3. Определи, что они НЕ делали (в сравнении с лояльными юзерами)
4. Зафиксируй эту пропасть (gap)

## Вопросы для Опроса при уходе (Exit Survey)
1. Какова главная причина вашей отмены подписки?
   [ ] Слишком дорого
   [ ] Нет функции, которая мне нужна
   [ ] Ушли к конкуренту (К какому именно?)
   [ ] Инструмент такого типа больше не нужен
   [ ] Слишком сложно пользоваться
   [ ] Другое: ___
2. Что могло бы заставить вас остаться?
3. К какому конкуренту вы перешли и почему?
4. Что должно измениться, чтобы вы вернулись к нам?

## Цепочка по Возврату (Win-Back Sequence)
- День 0: Подтверди отмену, оставь дверь открытой
- День 7: Поделись новым / что изменилось с момента их ухода
- День 30: Торг (1 месяц бесплатно, открытие спецфичи)
- День 90: Финальная проверка — без продаж, искреннее любопытство
