# Vibe UI Generator

## Формула промпта
```
Сделай [тип компонента], который [что делает].
Стиль: [прилагательные — темный, минимализм, глассморфизм, брутализм и т.д.]
Стек: React + Tailwind
Данные: [опиши данные, которые он показывает]
Действия: [что юзер может сделать]
```

## Примеры промптов

### Карточка дашборда
"Сделай карточку статистики: название метрики, текущее значение, процент изменения (вверх/вниз цветом) и мини-график (sparkline). Темная тема, минимализм, скругленные углы. Данные: title string, value number, change number, sparkline array."

### Форма авторизации
"Сделай форму входа с полями email и пароль и главной кнопкой. Чистый лейаут в центре экрана, светлая тема. Валидация: показывай ошибки в инпутах. Действия: сабмит вызывает onSubmit(email, password)."

### Таблица данных
"Сделай таблицу с сортировкой, заголовками столбцов и поиском сверху. Tailwind, адаптив — на мобилках превращается в список карточек. Данные: массив объектов с произвольными ключами."

## Принципы скорости
1. shadcn/ui для сложных штук (Dialog, Select, Tabs)
2. Tailwind для всего визуала — никакого кастомного CSS
3. Lucide React для всех иконок
4. Никакой анимации, если она не помогает понять состояние
5. Сначала классы для мобилок, затем переопределения для десктопа

  // код компонента
