# Архитектор Системы Компонентов Figma

## Иерархия Atomic Design
```
Токены → Атомы → Молекулы → Организмы → Шаблоны → Страницы
```

### Токены (базовый слой)
- Цвет: `color/brand/primary/500`, `color/neutral/100`
- Типографика: `font/size/body-md`, `font/weight/semibold`
- Отступы (Spacing): `space/2` (8px), `space/4` (16px)
- Скругления (Radius): `radius/sm` (4px), `radius/full` (9999px)
- Тени (Shadow): `shadow/sm`, `shadow/md`, `shadow/lg`

### Атомы (одноцелевые элементы)
- Кнопка, Инпут, Чекбокс, Бейдж, Аватар, Иконка, Разделитель
- Каждый атом: База + Варианты размера + Варианты состояния + Варианты темы

### Молекулы (составные элементы)
- Поле ввода (InputField) (Лейбл + Инпут + Подсказка)
- Карточка (Card) (Изображение + Заголовок + Описание + Действия)
- Элемент меню (MenuItem) (Иконка + Лейбл + Хоткей)

## Конвенция именования вариантов
```
Компонент/Размер/Состояние/Тема
Button/MD/Hover/Primary
Input/SM/Error/Default
```

## Правила Auto-Layout
- Каждый компонент использует авто-лейаут (никакого ручного позиционирования)
- По горизонтали: hug/fill, никогда не используй фиксированную ширину в гибких компонентах
- Отступы (Padding): используй только токены отступов
- Расстояния (Gap): используй только токены отступов

## Шаблон документации компонента
Для каждого компонента задокументируй:
1. Usage: когда использовать этот компонент
2. Don'ts: типичные ошибки использования
3. Variants: скриншот всех состояний
4. Props: таблица свойств Figma
5. Dev handoff: соответствие коду и токенам

## Экспорт токенов для разработки
- Экспортируй токены как JSON (плагин Tokens Studio)
- Свяжи с CSS-переменными или конфигом Tailwind
- Держи имена токенов в Figma идентичными именам переменных в коде
