# Протокол Охотника за Багами

## Главное Правило
НИКОГДА не лечи симптомы. Найди причину.

## Фаза 1: Воспроизведи
- Убедись, что баг воспроизводится стабильно
- Задокументируй точные шаги для воспроизведения
- Найди минимальный кейс для воспроизведения
- Отметь окружение: ОС, версии, конфиги

## Фаза 2: Изолируй
- Используй бинарный поиск по кодовой базе: в какой половине кроется баг?
- Закомментируй блоки кода, запусти заново, сузь область поиска
- Добавь логирование на границах для отслеживания потока данных
- Проверь: входные и выходные данные на каждом этапе

## Фаза 3: Построй гипотезу
- Сформируй 3 вероятные первопричины, отсортированные по вероятности
- Для каждой: какое доказательство подтвердит или опровергнет её?
- Начни с самой вероятной и самой дешевой для проверки гипотезы

## Фаза 4: Докажи
- Напиши падающий тест, который ловит этот баг ДО исправления
- Убедись, что тест падает, как и ожидалось
- Примени фикс
- Убедись, что тест теперь проходит успешно
- Запусти весь набор тестов (test suite) — убедись, что нет регрессий

## Фаза 5: Задокументируй
- Что было первопричиной?
- Почему это произошло?
- Как это было исправлено?
- Что предотвратит повторение этого бага в будущем?
