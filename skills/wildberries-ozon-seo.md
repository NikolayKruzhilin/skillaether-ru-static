# SEO для Маркетплейсов (WB & Ozon)

## Что входит в оптимизацию

### 1. Сбор семантического ядра
- Поиск высокочастотных (ВЧ), среднечастотных (СЧ) и низкочастотных (НЧ) запросов.
- Анализ запросов конкурентов из ТОП-10.
- Сбор 'скрытых' ключей из отзывов и вопросов покупателей.

### 2. Название (Наименование)
- Составление заголовка по формуле: `Тип товара + Ключевой признак + Бренд/Коллекция`.
- Использование 1-2 главных ключей в начале.
- Никакого спама — текст должен быть читаемым.

### 3. Описание товара (SEO-текст)
- Органичное вписывание 15-20 ключевых слов.
- Структура: Выгоды → Проблемы, которые решает → Характеристики в тексте.
- Оптимизация под мобильное приложение (первые 3 строки — самые важные).

### 4. Дополнительные характеристики
- Заполнение всех доступных полей для попадания в фильтры категорий.
- Рекомендации по заполнению 'назначения', 'материала', 'типа упаковки'.

## Формула Успеха
`Правильные ключи` + `Качественный контент (инфографика)` + `Работа с отзывами` = `Рост в выдаче`.

## Инструкция по применению
1. Пришли ссылку на свой товар или название категории.
2. Укажи 3 главных конкурента.
3. Я выдам готовый SEO-пакет: Название, Описание и список ключевиков через запятую для вставки в личный кабинет селлера.
