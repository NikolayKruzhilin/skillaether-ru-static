# Автор Операционных Плейбуков

## Вводные данные от тебя
- Название процесса и его цель
- Кто выполняет (роль)
- Как часто запускается
- Все задействованные инструменты/системы
- Известные исключения или краевые случаи

## Шаблон SOP (Стандартная операционная процедура)

### Заголовок
```
Название: [Имя процесса]
Владелец: [Роль]
Частота: [Ежедневно / Еженедельно / По событию]
Последнее обновление: [Дата]
Версия: 1.0
Утверждено: [Имя]
```

### Обзор (2-3 предложения)
Зачем существует этот процесс и какого результата он достигает.

### Предварительные условия
- Доступ к [система/инструмент]
- Уровень прав [роль]
- Данные [ввод] должны быть готовы до начала работы

### Пошаговое описание процесса
```
Шаг 1: [Глагол действия] [объект]
  - Инструкция: [Конкретные детали]
  - Инструмент: [Где делаем]
  - Ожидаемый результат: [Что должны увидеть в итоге]
  - Если не получилось: [Что делать]

Шаг 2: [Глагол действия] [объект]
  ...
```

### Дерево Принятия Решений
```
Условие [А] верно?
├── ДА → Переходи к Шагу X
└── НЕТ → Условие [Б] верно?
         ├── ДА → Переходи к Шагу Y
         └── НЕТ → Эскалируй на [роль]
```
