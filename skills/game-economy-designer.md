# Дизайнер Игровой Экономики

## Архитектура Экономики

### Уровни Валют (Currency Tiers)
```
Тир 1 — Твердая валюта (Premium): Гемы, Золото, Кристаллы
  Источник: Покупка за реальные деньги, редчайшие ивенты
  Сток (трата): Премиум-предметы, скип таймеров, косметика
  Правило: Никогда не давай зарабатывать премиум чересчур легко

Тир 2 — Мягкая валюта (Earned): Опыт (XP), Монеты, Звезды
  Источник: Геймплей, ежедневные награды, квесты
  Сток (трата): Апгрейды, крафт, обычные предметы
  Правило: Игрок всегда должен чувствовать прогресс, валюта не должна быть в дефиците до отчаяния

Тир 3 — Специальная валюта: Ивентовые токены, сезонные очки
  Источник: Только ограниченные по времени события
  Сток (трата): Эксклюзивные предметы, которые исчезают вместе с ивентом
```

## Баланс Источников и Стоков (Source-Sink)
```
Скорость Валюты = Доход в день - Траты в день

Здоровая ситуация:
  Доход: 500 монет/день (квесты + битвы)
  Траты: 450 монет/день (апгрейды + расходники)
  Чистый итог: +50 (мягкое накопление)

Инфляция (плохо):
  Доход: 1000 монет/день
  Траты: 100 монет/день
  Итог: Валюта обесценивается, товары в магазине игнорируются

Дефляция (тоже плохо):
  Доход: 200 монет/день
  Траты: 500 монет/день
  Итог: Игроки чувствуют голод, бросают игру (churn)
```

## Дизайн Кривой Прогрессии
```
Уровень Силы против Времени:
- Часы 0-5:    Быстрый ранний прогресс (дофаминовый крючок)
- Часы 5-20:   Умеренный темп (развитие навыков)
- Часы 20-50:  Замедленные, но значимые вехи
- Часы 50+:    Системы престижа / эндгейм контент

Формула стоимости апгрейда (геометрическая прогрессия):
  cost(level) = base_cost × growth_rate^level
  например, cost(n) = 100 × 1.5^n
```

## График наград (Variable Ratio — самый вовлекающий)
- Фиксированный (каждые N действий) → предсказуемо, меньше азарта
- Переменный (в среднем каждое N действие) → эффект слот-машины, очень вовлекает
- Фиксированный интервал (ежедневная награда) → хорошо для формирования привычки
- Переменный интервал (сюрприз-награда) → восторг + удержание (retention)

## Правила Честного F2P
- Премиум валюта покупает косметику и время, а не силу (избегай P2W)
- Бесплатные игроки могут достичь того же уровня силы — просто медленнее
- VIP-киты (киты/whales) не должны портить игру бесплатным игрокам
- Каждая покупка должна ощущаться как честная сделка, а не как эксплуатация
