# Конкурентный Анализ

## Шаг 1: Идентификация Конкурентов
Кого мы наносим на карту:
- **Прямые**: Тот же продукт, тот же клиент
- **Косвенные**: Другой продукт, тот же job-to-be-done (потребность)
- **Новые игроки**: Новички или возникающие угрозы из смежных ниш

Где искать: G2, Product Hunt, Crunchbase, Google (запрос "лучший софт для [категория]")

## Шаг 2: Шаблон для сбора данных
Для каждого конкурента запиши:
```
Название:
Сайт (URL):
Год основания / Инвестиции:
Целевой клиент (ICP):
Цены (Тарифы, суммы):
Главный оффер (Заголовок H1 на сайте):
Ключевые фичи (топ-5):
Самые громкие клиенты:
Рейтинг на G2/Capterra + топ-жалоба в отзывах:
```

## Шаг 3: Карта Позиционирования
Выбери 2 оси координат, важных для рынка:
```
Примеры осей:
- Цена (дешево ↔ премиум)
- Сложность (для новичков ↔ enterprise-система)
- Охват фич (узкоспециализированно ↔ платформа все-в-одном)
- Скорость (настройка: часы ↔ месяцы)
```
Нанеси конкурентов на график. Найди зоны (White space), где пусто.

## Шаг 4: Майнинг месседжей
У каждого конкурента найди:
- Их H1 (с главной страницы)
- Топ-фразы из их лучших 리뷰 على G2
- Их рекламные объявления (Библиотека рекламы Meta, Google Transparency)
- Их ключевые SEO-запросы (через Similarweb или Ahrefs)

## Шаг 5: Анализ сентимента клиентов
Прошерсти: Reddit, G2, Trustpilot, Twitter(X) по запросу "[конкурент] скатился" или "перешел с [конкурента]"
Ищи:
- Повторяющиеся жалобы (там твои возможности)
- Повторяющиеся похвалы (то, под что придется подстраиваться)
- Триггеры ухода (что заставляет их переключаться на другие продукты)

## Структура Готового Отчета
1. Executive Summary (3 ключевых буллита)
2. Профили конкурентов (1 страница на каждого)
3. Карта позиционирования
4. Матрица сравнения фич
5. Упущения в месседжах конкурентов
6. Рекомендованные углы для дифференциации от них
