# Библиотека Паттернов Мобильного UX

## Ключевые различия iOS и Android
| Паттерн | iOS | Android |
|---------|-----|--------|
| Навигация назад | Свайп вправо / Кнопка 'Назад' слева сверху | Системный жест 'Назад' / Кнопка назад |
| Главное действие | Справа внизу / Таб-бар | FAB (плавающая кнопка внизу справа) |
| Навигация | Tab bar (снизу, 3-5 пунктов) | Bottom nav / Navigation drawer (бургер) |
| Меню | Action sheets (выезжают снизу) | Bottom sheets / Меню 'три точки' |
| Алерты | Центрированный модальный диалог | Snackbar для некритичных событий |

## Паттерны Навигации

### Нижний Таб-бар (iOS) / Bottom Navigation (Android)
- Максимум 3-5 направлений
- Иконки + подписи для ясности
- Четко выделенное активное состояние
- Бейджи (счетчики) для уведомлений

### Навигация на Жестах
- Свайп для возврата назад (основной паттерн iOS)
- Свайп вниз для закрытия шторки/окна
- Pull to refresh (потяни для обновления) в списках
- Свайп для удаления/архивации элементов списка

## Паттерны Форм
- Вызывай правильный тип клавиатуры для каждого инпута
  - Email: `keyboardType="email-address"`
  - Телефон: `keyboardType="phone-pad"`
  - Цифры: `keyboardType="numeric"`
- Инлайновая валидация (сразу, а не после нажатия 'отправить')
- Авто-переход между полями, где это возможно
- Кнопка 'Готово' на клавиатуре для последнего поля

## Правила Точек Касания (Touch Target)
- Минимум: 44×44pt (iOS) / 48×48dp (Android)
- Комфортно: 56×56pt
- Расстояние между целями: минимум 8pt

## Паттерны Обратной Связи (Feedback)
- **Мгновенный** (0-100 мс): визуальное состояние нажатой кнопки
- **Короткий** (100-500 мс): тактильная отдача (Haptic) для важных действий
- **Средний** (500 мс-1 с): индикатор загрузки
- **Длинный** (>1 с): прогресс-бар с примерным временем ожидания

## Онбординг
- Максимум 3-4 экрана онбординга
- Всегда давай кнопку "Пропустить"
- Открытие фич (Feature discovery) > обучение фичам (дай им исследовать)
- Пустые состояния (empty states) при первом запуске — это возможность для онбординга
