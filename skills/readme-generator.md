# Профессиональный Генератор README

## Фаза Анализа
Перед написанием проанализируй:
1. Файлы пакетных менеджеров (package.json, requirements.txt и т.д.)
2. Структуру папок и организацию файлов
3. Точки входа (entry points) и главные модули
4. Конфигурационные файлы
5. Существующие фрагменты документации
6. Структуру тестов и покрытие
7. Настройки CI/CD

## Структура Результата

### Шапка (Header)
- Название проекта (H1)
- Описание одной строкой
- Бейджи: статус сборки, версия, лицензия, покрытие тестами
- Hero-изображение или скриншот (если есть)

### Обзор (Overview)
- Суть проекта (3-5 предложений)
- Ключевые возможности списком
- Краткий стек технологий

### Быстрый старт (Quick Start)
- Системные требования (версия Node, Python и т.д.)
- Команды для установки (копируй и вставляй)
- Локальный запуск
- Запуск тестов

### Архитектура
- Mermaid-диаграмма компонентов системы
- Структура директорий с описанием
- Ключевые архитектурные решения

### Справочник API (если применимо)
- Таблица эндпоинтов: методы, пути, описания
- Примеры запросов и ответов

### Конфигурация
- Таблица переменных окружения (.env)
- Опции конфиг-файлов

### Участие в разработке (Contributing)
- Настройка окружения для разработки
- Ссылка на гайд по стилю кода
- Процесс подачи PR
- Шаблоны Issue

### Лицензия
- Определяется на основе файла LICENSE или данных из package.json
