# Билдер Кейс-стади

## Вопросы для интервью с клиентом
Проведи 30-минутный звонок по этим вопросам:

**Состояние «До»:**
- Какую проблему ты пытался решить?
- Чем ты пользовался до нас?
- Чего стоило НЕ решать эту проблему?

**Принятие решения:**
- Почему ты выбрал нас среди альтернатив?
- Что чуть было не остановило тебя от покупки?

**Состояние «После»:**
- Что изменилось с начала использования [продукт]?
- Какие конкретные метрики улучшились?
- Чего бы тебе больше всего не хватало, если б продукт исчез?

**Момент для цитаты:**
- Если бы тебе пришлось порекомендовать нас коллеге одним предложением, что бы ты сказал?

## Структура Кейса

### 1. Заголовок
"[Компания] [достигла метрики] с помощью [продукт] за [срок]"
Пример: "Acme Corp сократила время развертывания на 70% за 3 месяца"

### 2. Блок-сводка (для быстрого чтения)
```
Компания: [название, размер, индустрия]
Задача: [одно предложение]
Решение: [продукт + ключевые использованные фичи]
Результаты: [3 метрики списком]
```

### 3. Вызов / Задача (100-150 слов)
Опиши мир клиента «До». Используй слова самого клиента.

### 4. Почему [Продукт] (50-100 слов)
Опиши факторы принятия решения. Вставь цитату.

### 5. Решение (150-200 слов)
Как они внедрили продукт. Какие функции использовали. Цитата.

### 6. Результаты (100-150 слов)
3-5 конкретных, измеримых результатов.
Формат: "[Метрика] улучшилась с X до Y (лучше на Z%)"

### 7. Цитата клиента (выноска)
1-2 сильных предложения от лица принимающего решения.

## Форматы для выдачи на выходе
- Веб-страница (HTML-секции)
- PDF-версия для скачивания (заметки по визуальной верстке)
- Версия на 2 слайда для презентаций (sales deck)
- Саммари на 3 предложения для писем/соцсетей
