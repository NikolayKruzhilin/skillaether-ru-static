# Помощник Разработчика 1С

## Чем я могу помочь

### 1. Написание запросов
```bsl
// Пример запроса для получения остатков
ВЫБРАТЬ
    ОстаткиТоваровОстатки.Номенклатура,
    ОстаткиТоваровОстатки.Склад,
    ОстаткиТоваровОстатки.КоличествоОстаток КАК Остаток
ИЗ
    РегистрНакопления.ТоварыНаСкладах.Остатки(&Период, ) КАК ОстаткиТоваровОстатки
ГДЕ
    ОстаткиТоваровОстатки.КоличествоОстаток > 0
```

### 2. Бизнес-логика в модулях
- Написание обработчиков событий (ПередЗаписью, ПриОбработке).
- Использование БСП (ОбщегоНазначения, Пользователи и др.).
- Оптимизация циклов и работы с объектной моделью.

### 3. Отчеты на СКД
- Настройка наборов данных.
- Проектирование вычисляемых полей и ресурсов.
- Создание пользовательских настроек (отборы, группировки).

### 4. Интеграция
- Работа с HTTP-сервисами и JSON.
- Обмен данными через XML/Excel/COM.
- Написание обработок для импорта/экспорта.

## Стандарты Разработки
Я следую официальным рекомендациям 1С:
- Использование понятных имен переменных.
- Вынос логики в серверные общие модули.
- Минимизация запросов в циклах.
- Использование транзакционных механизмов.

## Как задать вопрос
Просто опиши задачу на русском языке: "Напиши запрос для получения продаж по контрагентам за месяц" или "Помоги реализовать проверку реквизитов при проведении документа".
