# Дизайнер Опросов

## Типы опросов и когда их использовать
| Тип | Цель | Длина |
|------|------|--------|
| NPS | Бенчмарк лояльности | 2 вопроса |
| CSAT | Удовлетворенность конкретным действием | 3–5 вопросов |
| PMF (Шон Эллис) | Проверка соответствия рынку | 5 вопросов |
| Поиск проблем | Понимание болей юзеров | 8–12 вопросов |
| Юзабилити | Оценка конкретной фичи | 6–10 вопросов |

## Правила составления вопросов
1. Один вопрос = одна идея (не спрашивай про два аспекта сразу)
2. Одинаковое направление шкал (1 — всегда худший вариант)
3. Добавляй опцию "Не применимо", чтобы не искажать статистику
4. Открытые вопросы (текстовые) — в самый конец (они требуют больше всего сил)
5. Начинай с простых вопросов, чтобы вовлечь пользователя

## Опрос PMF по Шону Эллису
```
В1: Как бы ты себя чувствовал, если бы не смог больше пользоваться [Продукт]?
[ ] Очень расстроен [ ] Немного расстроен [ ] Совершенно не расстроен

В2: Какому типу людей, по твоему мнению, [Продукт] принесет больше всего пользы?
[открытый текст]

В3: Какую главную пользу ты получаешь от [Продукт]?
[открытый текст]

В4: Как мы можем улучшить [Продукт] для тебя?
[открытый текст]
```
Интерпретация: 40%+ ответов "Очень расстроен" — сильный сигнал Product-Market Fit.

## Лучшие практики Шкалы Лайкерта
- Используй 5-балльную или 7-балльную шкалу (нечетное число позволяет выбрать нейтральный вариант)
- 5 баллов: Категорически не согласен / Не согласен / Нейтрально / Согласен / Полностью согласен
- Подписывай ВСЕ точки шкалы, а не только крайние
- Держи формат шкал одинаковым во всем опросе

## Вопросы-скринеры
Всегда сначала проверяй респондента:
"Какая роль лучше всего тебя описывает?" → отсекай нецелевые сегменты
"Как часто ты [действие]?" → нужен ли нам тот, кто пользуется продуктом редко?

## Фреймворк Анализа
- Количественный: Средний балл, NPS = % сторонников - % критиков
- Качественный: Аффинити-маппинг (группировка) текстовых ответов
- Сегментация: Сравнивай оценки разных когорт пользователей
- Бенчмарк: Сравнивай свои цифры со средними показателями в индустрии
