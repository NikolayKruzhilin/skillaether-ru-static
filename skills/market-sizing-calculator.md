# Калькулятор Размера Рынка

## Два подхода к расчету

### Сверху вниз (Top-Down)
Начинай с огромного известного рынка и отсекай лишнее до своего сегмента.
```
Мировой рынок CRM: $80B (Gartner 2024)
× Релевантный сегмент (SMB): 30% → $24B
× Твоя география (РФ/СНГ): 5% → $1.2B
× Достижимые аккаунты: ~25% → $300M TAM
```

### Снизу вверх (Bottom-Up) — больше доверия у инвесторов
Строится на основе юнит-экономики.
```
Всего целевых аккаунтов (компаний): 50,000
× Доступно по твоему фильтру ICP: 40% → 20,000
× Средний чек (ACV): $12,000/год
SAM = 20,000 × $12,000 = $240M

SOM (реалистичный захват за 3 года): 2% = $4.8M ARR
```

## Источники данных
- РБК Исследования, Statista — выручка отраслей
- LinkedIn Sales Navigator — количество аккаунтов по фильтрам
- Росстат / Налоговая отчетность — количество предприятий по ОКВЭД
- Crunchbase/PitchBook — инвестиции в нише (прокси активности рынка)
- Отчетность публичных конкурентов — реальная выручка + комментарии по рынку

## Вводные данные для модели
1. Описание продукта/услуги
2. Профиль идеального клиента (ICP)
3. Модель ценообразования и средний чек (ACV)
4. География
5. Любые известные отчеты по рынку или данные о выручке конкурентов

## Таблица Чувствительности (Sensitivity Table)
```
                   Консервативно  База   Оптимистично
Доступная часть %:    15%         25%         40%
Конверсия %:           1%          2%          5%
Средний чек (ACV):    $8K         $12K        $18K
SOM Year 3:          $1.2M       $4.8M       $18.7M
```

## Советы по презентации инвесторам
- Начинай с bottom-up, подтверждай через top-down
- Указывай источник для КАЖДОГО допущения
- Покажи, КАК именно ты придешь к SOM (реалистичный план захвата)
- Не используй фразу "всего 1% от огромного рынка" — для инвесторов это красный флаг
