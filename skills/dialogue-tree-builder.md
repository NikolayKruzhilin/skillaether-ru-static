# Билдер Дерева Диалогов

## Архитектуры Деревьев Диалогов

### Hub-and-Spoke (самая частая)
```
Корневой узел → Выбор A → Ветка → Возврат в корень
                → Выбор B → Ветка → Возврат в корень
                → Выбор C → Ветка → Конец
```
Лучше всего подходит для: RPG-разговоров, сбора информации

### Линейная с ветвлением (нарративная)
```
A → B → Выбор → C1 (темный путь)
              → C2 (нейтральный)
              → C3 (светлый путь)
     C1/C2/C3 → D → E (конвергенция/слияние)
```
Лучше всего подходит для: Сюжетных поворотов, важных решений с долгоиграющими эффектами

### Полное ветвление (дорого, но весомо)
Каждый выбор ведет на уникальный путь. Используй только для ключевых моментов.

## Шаблон Дизайна Узла
```
ID Узла: NPC_MERCHANT_001
Спикер: Торговец (грубый голос)
Реплика: "Раньше я таких, как ты, здесь не видел. Что тебе нужно?"

Выбор Игрока:
  [A] "Я ищу работу." → NODE_WORK_OFFER
  [B] "Просто прохожу мимо." → NODE_DISMISSAL
  [C] "Я хочу посмотреть товары." → SHOP_OPEN
  [D] [Только если: player_has_guild_badge] "Дело гильдии." → NODE_GUILD_CHAT

Флаги при входе: met_merchant = true
Условия проверки: player_has_guild_badge
```

## Скрипт Ink (Inkle)
```
=== merchant_greeting ===
Торговец: Раньше я таких, как ты, здесь не видел.
+ [Я ищу работу.] → work_offer
+ [Просто прохожу мимо.] → dismissal
+ {player_has_guild_badge} [Дело гильдии.] → guild_chat
- → END

=== work_offer ===
Торговец: Работу, значит? Может быть, у меня что-то и найдется.
...
```

## Правила Голоса Персонажа
Для каждого NPC определи:
- **Словарный запас**: формальный/разговорный, архаичный/современный, уровень жаргона
- **Паттерны речи**: короткие предложения против длинных, вопросы против утверждений
- **Темы**: о чем они знают, что отказываются обсуждать
- **Эмоциональный диапазон**: как они выражают гнев, страх, радость

## Дизайн Последствий
Помечай выборы флагами, чтобы мир реагировал на них:
- `+reputation_guard` — стражники будут дружелюбнее позже
- `+quest_lied_to_mayor` — влияет на реакцию мэра
- `romance_interest = 1,2,3` — отслеживание уровня отношений
