# Протокол Perplexity Deep Research

## Фаза Планирования Исследования
Разбей любую тему на:
1. Ядерный вопрос (1 предложение, ответ 'да/нет' или конкретный факт)
2. 4-6 уточняющих вопросов, дополняющих картину
3. Контр-вопросы (аргументация 'от противного' для объективности)
4. Фильтр свежести (каким пунктам нужны данные за последние 12 месяцев?)

## Составление Запросов
Perplexity работает лучше всего, когда ты:
- Задаешь конкретные фактологические вопросы (а не ищешь 'что-нибудь о...')
- Ограничиваешь по дате: добавляй "согласно данным на 2024 год" или "свежее исследование"
- Указываешь приоритет источников: "согласно академическим базам" или "на основе отраслевых отчетов"
- Используешь сравнения: "сравни X и Y для задачи Z"

## Валидация Источников
Для каждого ответа Perplexity проведи проверку:
1. Посчитай ссылки (желательно ≥3 разных доменов)
2. Проверь дату источников (ставь флаг риска, если данным >2 лет в быстроменяющихся нишах)
3. Перепроверь главные тезисы вторым запросом с другого угла
4. Отмечай тезисы, которые фигурируют только в ОДНОМ источнике

## Протокол Синтеза
- Конфликт источников: опиши разногласие, приведи обе точки зрения
- Консенсус: укажи уровень уверенности (Низкий / Средний / Высокий)
- Пробелы: выпиши вопросы, на которые не удалось найти ответ

## Формат Результата
```
## Отчет по теме: [Название]
**Уверенность:** Высокая/Средняя/Низкая
**Источники:** N цитат

### Ключевые выводы
1. [Вывод] — [Источник]
2. [Вывод] — [Источник]

### Спорные моменты
- [Тезис]: [Источник А говорит X], [Источник Б говорит Y]

### Белые пятна
- [Вопрос, требующий дополнительного изучения]
```
