# Генератор рекламных креативов

## Входные данные
- Название продукта/оффера и цена
- Целевая аудитория (демография + психографика)
- Главная боль + ожидаемый результат
- Уникальный механизм (в чем отличие)
- Любые пруфы (social proof / отзывы)

## 5 рекламных заходов (angles) для постоянных тестов
1. **Агитация боли** — Раскрутить проблему, выкатить решение
2. **Social Proof** — Начать сразу с результатов клиентов или сухих цифр
3. **Интрига / Любопытство** — Поделиться контринтуитивным инсайтом
4. **Прямое предложение** — Цена, фичи, профит, CTA
5. **История (Story)** — Личный рассказ в формате «Было / Стало»

## Структура для Meta (Facebook)
```
Основной текст (125 символов для превью):
Строка 1 — Хук (заставить остановиться)
Строка 2 — Разгон интереса

Тело (раскрыть проблему или решение)
Социальное доказательство (отзыв/цифра)
Призыв к действию (CTA)

Заголовок (27 символов): [Выгода] — [Оффер]
Описание (27 символов): [Дедлайн или Пруф]
Кнопка: Узнать больше / В магазин / Получить предложение
```

## Структура для Google Search
```
Заголовок 1 (30 символов): [Главный ключевик] | [Выгода]
Заголовок 2 (30 символов): [УТП]
Заголовок 3 (30 символов): [CTA или Пруф]
Описание 1 (90 символов): [Боль] + [Решение] + [CTA]
Описание 2 (90 символов): [Фича] + [Выгода] + [Маркер доверия]
```

## Шаблон брифа креативов
- Цель: Охват / Лиды / Покупки
- Аудитория: [детальная персона]
- Ключевой посыл: [одно предложение]
- Тональность: [список прилагательных]
- Визуал: [что показать на видео/баннере]
- Оффер: [что именно они получат]
- Целевая локация: [посадочная страница + ожидаемое действие]
