# Аудит Безопасности Кода

## Протокол Сканирования

### Фаза 1: Секреты и Доступы
- Поиск захардкоженных API-ключей, паролей, токенов
- Проверка файлов .env на наличие чувствительных дефолтных значений
- Проверка .gitignore: скрыты ли важные файлы?
- Поиск секретов в истории коммитов и ссылках

### Фаза 2: Анализ по OWASP Top 10
1. Инъекции (Injection) — SQL, NoSQL, команды ОС, LDAP
2. Проблемы аутентификации — слабое управление сессиями, незащищенные учетные данные
3. Утечка чувствительных данных — нешифрованные PII (персональные данные), слабый хешинг
4. XXE — атаки через внешние XML-сущности
5. Нарушение контроля доступа — повышение привилегий, IDOR
6. Ошибки конфигурации — дефолтные доступы, слишком подробные ошибки для юзеров
7. XSS — межсайтовый скриптинг (отраженный, сохраненный, DOM)
8. Небезопасная десериализация — парсинг недоверенных данных
9. Использование известных уязвимостей — устаревшие библиотеки/зависимости
10. Недостаточное логирование — отсутствие аудиторских следов

### Фаза 3: Аудит зависимостей
- Проверка версий пакетов на наличие известных CVE
- Поиск заброшенных (unmaintained) библиотек
- Выявление слишком широких диапазонов версий (permissive ranges)
